## ① 주제 선택 / Choosing one problem

| 항목 Item | 내용 |
|---|---|
| 선택한 주제 Chosen | 술자리 귀가 시 막차를 놓치지 않도록, 집까지의 지하철 막차 기준 **"최대 몇 시 몇 분에 일어나야 하는지"**를 거꾸로 계산해 알려주는 서비스 (막차연산알림) |
| 선택 근거 Why | 지도앱은 "지금 출발하면" 기준의 경로만 보여줘서, 술집에서 역까지의 도보·환승 도보·중간 종착열차를 반영한 **실제 일어날 시각**은 사용자가 직접 계산해야 한다. 술자리 분위기 때문에 계산을 미루다 막차를 놓치면 택시비 등 금전적 손해로 이어진다. 같은 술자리 친구들의 일어날 시각을 함께 볼 수 있다는 점도 기존 도구와 다르다. 다만 핵심(Must)은 **한 사람의 막차 계산**이고, 친구들과 함께 보는 팀 기능은 1인 기능 완성 직후 붙이는 Could 1순위로 둔다. |

## ② 성공 기준 가져오기 / Success criteria from Week 3

| 3주차 성공 기준 원문 Original (Week 3) | 모호한 표현 Vague words |
|---|---|
| 술자리 중에 "최대 몇 시 몇 분에 일어나야 하는지"를 바로 알 수 있고, 그 시각에 맞춰 일어나면 막차를 탈 수 있다. 같이 있는 친구들도 각자 일어날 시각을 한눈에 볼 수 있다. | **바로** 알 수 있고, 막차를 **탈 수 있다**, **한눈에** 볼 수 있다 |

> 모호한 표현을 아래 AC에서 숫자로 바꿨습니다.
> - "바로" → 3초 이내 (AC-1)
> - "막차를 탈 수 있다" → 일어날 시각 = 열차 출발 − 도보 − 여유 시간, 중간 종착열차 제외 (AC-1, AC-2)
> - "한눈에" → 일어날 시각 오름차순 정렬 (AC-3, 팀 기능 · Could 1순위)

## ③ Acceptance Criteria

최소 정상 경로 2개 + 실패 경로 1개. **판정 방법** 칸이 비면 아직 명세가 아닙니다.
At least two normal paths + one failure path. If "How to check" is empty, it is not yet a spec.

| # | 경로 Path | EARS 문장 Sentence | 판정 방법 How to check |
|---|---|---|---|
| AC-1 | 정상 Normal | WHEN 사용자가 출발역(술자리와 가장 가까운 역), 도착역(집과 가장 가까운 역), 요일 구분을 입력하고 [계산하기] 버튼을 누르면 THE 막차연산알림 시스템은 SHALL 3초 이내에 "일어날 시각"(HH:MM)을 화면에 표시한다. 일어날 시각은 **탑승 열차 출발 시각 − 출발역까지의 도보 시간(기본 7분) − 여유 시간(기본 5분)**으로 계산한다. | 1. 홍대입구 → 대화, 평일, 도보 7분, 여유 5분으로 입력 후 버튼 클릭. 2. 선택된 첫 열차 출발이 23:08이면 3초 이내에 "22:56"이 표시되는지 확인. 3. 도보·여유 시간을 바꿨을 때 결과가 그만큼 달라지는지 확인. |
| AC-2 | 정상 Normal | WHEN 경로 후보에 목적지(도착역)까지 가지 않는 중간 종착열차(예: 구파발행)가 포함되어 있으면 THE 막차연산알림 시스템은 SHALL 해당 열차를 선택 경로에서 제외하고, 제외 사유("목적지 미도달")와 함께 제외 목록에 표시한다. | 1. 도착역이 대화인 상태에서 23:45 구파발행 열차가 경로 후보에 있는 케이스로 입력. 2. 선택 경로(selectedRoute)에 구파발행 열차가 없는지 확인. 3. 제외 목록에 해당 열차와 사유가 표시되는지 확인. |
| AC-3 | 정상 Normal (Could: 팀 기능) | WHEN 같은 팀(술자리)에 2명 이상의 일어날 시각 계산이 끝나면 THE 막차연산알림 시스템은 SHALL 모든 사용자의 일어날 시각을 **빠른 순(오름차순)**으로 정렬해 그룹 화면에 표시한다. | 1. 3명이 각각 22:56, 22:30, 23:10으로 계산되도록 입력. 2. 그룹 화면 순서가 22:30 → 22:56 → 23:10인지 확인. 3. 한 명의 값을 바꾼 뒤 순서가 즉시 갱신되는지 확인. |
| AC-4 | 실패 Failure | IF 현재 시각이 도착역까지 갈 수 있는 마지막 열차의 출발 시각을 지났으면 THEN THE 막차연산알림 시스템은 SHALL 일어날 시각 대신 상태를 `MISSED`로 표시하고 "오늘 막차를 놓쳤습니다" 안내 문구를 표시한다. | 1. 마지막 열차 출발이 23:50인 경로에서 현재 시각을 23:55로 설정(테스트 입력). 2. 상태가 `MISSED`이고 안내 문구가 표시되는지 확인. 3. 지난 시각이 "일어날 시각"으로 표시되지 않는지 확인. |
| AC-5 | 실패 Failure | IF 경로 검색 API(ODsay) 호출이 실패하거나 5초 안에 응답이 없으면 THEN THE 막차연산알림 시스템은 SHALL 일어날 시각을 표시하지 않고 "경로를 불러오지 못했습니다. 다시 시도해 주세요" 문구와 [다시 시도] 버튼을 표시한다. | 1. API 키를 일부러 틀리게 하거나 네트워크를 끊고 [계산하기] 클릭. 2. 5초 이내에 에러 문구와 재시도 버튼이 표시되는지 확인. 3. 이전 계산 결과가 남아 있지 않은지 확인. |

> AC-1, AC-2, AC-4, AC-5는 1인 기준 Must(MVP)를 검증하고, AC-3은 MVP 직후 추가하는 팀 기능(Could 1순위)을 검증합니다.
