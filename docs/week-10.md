## 막힌 지점 / What is blocked

**ODsay API 키가 등록된 IP에서만 동작해서, 저장해 두지 않은 역 쌍은 장소가 바뀌면 계산이 안 된다.**

- 경로 검색(ODsay `subwayPath`)과 역 ID 조회(`searchStation`)는 ODsay LAB에 등록한 공인 IP에서만 성공한다. 와이파이를 바꾸면 공인 IP가 바뀌어 `ApiKeyAuthFailed`가 난다.
- 이번 주에 역 목록을 수도권 650개 역으로 늘리면서, 역 ID를 미리 받아 두지 않고 **처음 계산할 때 받아서 저장**하도록 바꿨다. 그래서 처음 계산하는 역 쌍은 반드시 ODsay를 불러야 하고, IP가 등록되지 않은 곳(강의실, 발표장)에서는 실패 화면이 뜬다.
- 저장해 둔 경로(`odsay_cache`: 홍대입구→대화, 왕십리→김포공항, 신도림→고속터미널, 천안→서울역)는 키 없이 계산되므로, 지금은 시연을 이 경로들로만 할 수 있다.

그 밖에 이번 주까지 막혔다가 풀린 것:

- 자정이 지나면 어젯밤 일어날 시각을 내일로 잡아 "23시간 남음"이 뜨던 문제 → 운행일 기준(04:00 시작)으로 비교하도록 수정
- 공공데이터포털(TAGO) 시간표가 느리고 노선 이름 표기가 ODsay와 달라('경의중앙'/'경의중앙선', '공항'/'공항철도') 매칭 실패 → 1~9호선은 서울교통공사 CSV 시간표를 서버 시작 때 미리 읽고, 나머지만 TAGO 사용
- 환승역에서도 막차를 고르던 문제 → 환승역에서는 막차가 아니라 바로 이어지는 열차를 타도록 수정, 환승 여유 기본값 2분으로 팀 결정

## 디버깅 요청 4요소 / Four parts of a debugging request

- 증상 Symptom: 집에서는 되던 새 역 쌍 계산이, 학교 와이파이에서는 "경로를 불러오지 못했습니다" 화면과 [다시 시도] 버튼만 나온다. 저장된 역 쌍(홍대입구→대화)은 같은 곳에서도 정상이다.
- 재현 Steps:
  1. ODsay LAB에 IP를 등록하지 않은 네트워크(예: 학교 와이파이)에 연결
  2. `.venv\Scripts\python -m uvicorn main:app --app-dir backend --reload`로 서버 실행
  3. http://localhost:8000 → [시작하기] → 출발역·도착역에 저장본이 없는 역 쌍(예: 사당 → 수원) 선택 → [계산하기]
- 기대 Expected: 일어날 시각, 예상 소요 시간, 탑승 열차와 환승역이 표시되고, 경로가 `odsay_cache`에 저장된다.
- 실제 Actual: ODsay가 `ApiKeyAuthFailed`를 돌려주고 API가 실패로 응답해 결과 화면 대신 실패 안내가 표시된다. 캐시 파일도 생기지 않는다. ODsay LAB 애플리케이션 설정에 현재 공인 IP를 추가하면 같은 입력이 정상 계산된다.

## **버린 기능과 이유 / Features dropped and why**

| 버린 기능 | 원래 우선순위 | 이유 |
|---|---|---|
| 막차 대안 경로 비교 (막차 직전 열차 1~2개) | Should | ODsay 경로를 역 쌍마다 1개(최단거리)만 받아 저장하는 구조로 정했다(토큰 제한 대응). 대안 경로를 보여주려면 호출 수와 캐시 구조를 다시 짜야 한다. |
| 현재 위치로 출발역 추천, 도보 시간 자동 계산, 막차 놓친 사람 대안 안내 | Could | 위치 권한·지도 API가 필요하다. 역 검색(부분 입력, 줄임말)으로 출발역 입력은 충분히 빨라서 우선순위를 낮췄다. |
| 10분 전 분홍색 강조 | Should(임박 표시의 일부) | 일어날 시각이 지나도 막차가 떠나기 전엔 아직 탈 수 있어서, 10분 전에 색을 바꾸면 오히려 혼란스러웠다. 막차 출발 전까지 노란색을 유지하고, 막차가 떠나면 "오늘 막차를 놓쳤어" 화면(빨간색)으로 바꾸는 것으로 정리했다. |
| 경로 "목록" 반환 (#2 명세) | 명세 변경 | ODsay 토큰 제한 때문에 최단거리 경로 1개만 받는 것으로 명세를 바꿨다. |

## 데모 시나리오 초안 / Draft demo scenario

> 발표장 IP 문제를 피하려고 **저장된 경로만** 사용한다. (필요하면 `ODSAY_CACHE_ONLY=1`로 실행)

1. **문제 소개 (30초):** "술자리에서 막차 시간만 보고 일어나면 늦는다. 역까지 걷는 시간, 나갈 준비 시간, 중간에 끊기는 열차까지 생각해야 한다."
2. **기본 계산:** [시작하기] → 출발역에 "홍대" 입력 → 자동완성에서 홍대입구 선택 → 도착역 "대화" 선택 → 요일이 오늘 날짜로 자동 선택된 것 보여주기 → [계산하기]
3. **결과 설명:** 일어날 시각, 예상 소요 시간, 탑승 열차와 대곡 환승 타임라인, 그리고 **못 타는 열차(능곡행)가 사유와 함께 제외**된 것을 짚는다.
4. **입력 반영:** 도보 시간을 7분 → 12분으로 바꾸면 일어날 시각이 5분 당겨지는 것 보여주기
5. **막차 놓침:** [시연 모드] → 지금 시각을 막차보다 늦게 설정 → "오늘 막차를 놓쳤어" 화면
6. **실패 경로:** [시연 모드] → 경로 조회 실패 흉내 → 실패 안내와 [다시 시도] → 다시 시도하면 정상 계산
7. (시간 남으면) 줄임말 검색 "고터" → 고속터미널, 신도림 → 고속터미널 계산
